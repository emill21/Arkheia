# Changelog

## 1.3 · Photos, videos and the Files permission (2026-11-10)

- Uses your watch's Files permission now, so Allow file access covers every file, not just photos and music
- New photo viewer: swipe between every photo in the folder, turn the crown or double-tap to zoom, drag to look around
- New video player: tap for controls, a progress ring around the screen, skip 10 seconds, turn the crown to scrub, double-tap to fill the screen
- New Gallery: every photo and video in a folder as thumbnails

## 1.2 · File access from Settings (2026-11-10)

- File access is now one button: Allow file access opens the switch in your watch's own Settings
- No switch on your watch? Allow photos, videos and music with the normal Allow pop-up instead
- Removed the Wireless debugging setup, so the app is much smaller again

## 1.1 · No computer needed (2026-11-10)

- Turn on file access right on the watch, no computer or phone needed: Arkheia pairs with your watch's own Wireless debugging and switches it on for you
- Type the pairing code straight into Arkheia's notification, so the code screen in Settings stays open
- Older watches with Debug over Wi-Fi just need you to tap Allow, no code
- Unlocking also lets Arkheia install APKs

## 1.0 · Arkheia on your watch (2026-11-10)

- Browse every folder on your watch, with folders first and sorting by name, date, size or type
- Open photos (turn the crown or double-tap to zoom), read text files and play music right on the watch
- Copy, move, rename and delete files and folders, and make new folders by voice or keyboard
- Storage: free space at a glance, what's using it by type, and your largest files
- Search by name, pin folders to the home screen, and jump back to recent files
- An Arkheia tile with free space and shortcuts into your files
